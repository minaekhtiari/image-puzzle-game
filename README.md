## Introduction

Welcome to the Donald Duck Android Interview Challenge 🦆

In this repo you can find a really barebones Android app. Your task is to build a simple sliding puzzle game.
The goal of this task is not only for us to see how you architect an app, but also to see what UI/UX decisions you take.

## Game rules

- The board consists of 8 vertically stacked tiles, each being a horizontal strip of the original image.
- When the game starts, the user sees the shuffled board.
- The game is won when all the pieces reconstruct the original image.
- When the game is won, track how long the session was by calling `PUT /events`.

## Other notes

1. You aren't required to design/implement a puzzle selection screen. You only need to implement the puzzle screen.
2. While this project is set up using different frameworks like: Hilt, Jetpack Compose, etc. You aren't obliged to use them. Use whatever you're most comfortable with.
3. Using AI is fine, as long as you disclose it.

Any questions feel free to ask.

Best of luck & have fun!
